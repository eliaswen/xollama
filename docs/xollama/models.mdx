xOllama runs every model Ollama runs, from the same registry. The models below
are published in the [mannix library on ollama.com](https://ollama.com/mannix)
and are either made for xOllama or use something only xOllama has. The library
has many more; that page lists them all.

```shell
xollama pull mannix/flux2-klein:4b
xollama run mannix/bonsai-2-27b
```

## A model that needs a later xOllama

A Modelfile's `REQUIRES` states the oldest version that can run the model, and a
pull by an older one is refused before anything is downloaded. In xOllama it can
name an xOllama release, not only an upstream version:

```
REQUIRES 0.40.3-xollama.3
```

Releases are ordered as their names read: a candidate (`0.40.3-rc.1.xollama`),
then the release (`0.40.3-xollama`), then its re-releases by number
(`0.40.3-xollama.1`, `.2`, … `.10`), and any release on a later upstream version
after all of them. A model that states an xOllama release is also refused when it
is loaded, so one that reached the store another way (created there, or copied
in) is answered by name:

```
model requires a newer xollama: v0.40.3-xollama.3 or later (this is v0.40.3-xollama.2)
```

A plain upstream version (`REQUIRES 0.40.3`) keeps upstream's meaning: any
xOllama built on that version or a later one passes, and it is checked at pull
only. Builds without a version (a local `go build`) pass every requirement.
Releases up to `v0.40.3-xollama.2` do not know the xOllama form and let such a
model through; the engine's own error is what they report.

## Ternary Bonsai 2 27B

[`mannix/Bonsai-2-27B`](https://ollama.com/mannix/Bonsai-2-27B): a 27B
reasoning model in 6 to 8.6 GB, with an optional draft head and vision tower.
It needs xOllama v0.40.3-xollama or later. Tags, speed and settings:
[Ternary Bonsai 2 27B](/xollama/bonsai).

## Models with a draft head

These carry a draft head (MTP) in their weights or as tags. On the opencoti
engine it is used without any setting; stock llama.cpp serves the model without
drafting. See [The drafter](/xollama/tweak#the-drafter).

| Model | What it is |
|---|---|
| [`mannix/omnimerge-v6`](https://ollama.com/mannix/omnimerge-v6) | A merge on Qwen3.8-27B with three Qwen3.6 fine-tunes; MTP and vision tags |
| [`mannix/omnimerge-v4-mtp`](https://ollama.com/mannix/omnimerge-v4-mtp) | The Qwen3.6-27B merge, MTP quants |
| [`mannix/qwen3.6-27b-a3b-coderx`](https://ollama.com/mannix/qwen3.6-27b-a3b-coderx) | A 184-expert cut of Qwen3.6-35B-A3B for coding; MTP and vision tags |
| [`mannix/Bonsai-2-27B`](https://ollama.com/mannix/Bonsai-2-27B) | The `mtp-` tags |

## Gemma 4 and its drafters

Gemma 4's drafter is a separate small file. The five published ones are on
Hugging Face, and `xollama tweak model MODEL --drafter=auto` attaches the right
one to any Gemma 4 model, fine-tunes and merges included. The list and the
measurements: [Gemma-4 drafters](/xollama/gemma4-drafter).

| Model | What it is |
|---|---|
| [`mannix/gemma4-98e-v7-coder`](https://ollama.com/mannix/gemma4-98e-v7-coder) | Gemma 4 26B-A4B pruned to 98 experts, for coding |
| [`mannix/gemma4-98e-v7-coderx`](https://ollama.com/mannix/gemma4-98e-v7-coderx) | The same, tuned further toward coding |
| [`mannix/gemma4-98e-v6-coder`](https://ollama.com/mannix/gemma4-98e-v6-coder) | The earlier version; its `mtp-Q4_K_M` tag comes with the drafter |
| [`mannix/gemma4-31b-he1`](https://ollama.com/mannix/gemma4-31b-he1) | Gemma 4 31B with pruned heads |
